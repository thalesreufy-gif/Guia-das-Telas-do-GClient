# Guia-das-Telas-do-GClient
O Guia das Telas do GClient é um manual visual e interativo, num único arquivo HTML. Ele documenta 48 telas do sistema, numeradas de 82 a 129, como complemento ao guia principal (versão de 26/10/2026). Ele serve de consulta rápida para onboarding de usuários, treinamentos e suporte, e como base para artigos da Central de Ajuda.
